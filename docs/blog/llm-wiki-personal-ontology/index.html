LLM Wiki 기반 개인 지식 온톨로지

메모와 대화가 다시 일하게 만드는 5편 블로그 시리즈

시리즈 목차

  • 1. 왜 나는 LLM Wiki 기반 개인 지식 온톨로지를 만들기 시작했나
    메모는 많은데 다시 못 쓰는 문제에서 시작한 실험
  • 2. LLM Wiki는 RAG와 뭐가 다를까
    찾기와 다시 쓰기의 차이
  • 3. 내 Obsidian Vault를 AI가 읽을 수 있게 바꾸는 법
    폴더 정리가 아니라 지식 구조 만들기
  • 4. 대화와 메모를 블로그 주제로 바꾸는 파이프라인
    콘텐츠는 새로 짜내는 게 아니라 다시 구조화하는 것
  • 5. 개인 지식 온톨로지로 보고서와 의사결정 자동화하기
    내 지식이 실제 판단으로 이어지는 구조

OpenClaw × Obsidian × LLM-Wiki 기반으로 개인 지식을 구조화하고 콘텐츠와 보고서로 재사용하는 과정을 정리한 시리즈입니다.
